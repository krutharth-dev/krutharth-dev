01 / Document privacy

ShareShield

Problem

Sensitive information can survive a redaction workflow when OCR misses text, detections are uncertain or export verification is incomplete. The project treats redaction as a reviewable workflow rather than a guarantee.

Architecture

Document→Local OCR→Candidate review→Redaction→Export verification

Design decisions

Separate recognition from redaction and expose verification outcomes. Support English and Kannada document review while keeping uncertain fields visible to the user. Retain the original document for controlled re-export.

Verification & evidence

Documented known limitations, scoped verification states, OCR evaluation tooling and regression coverage. The repository has open acceptance-testing work for downloaded files and independent Kannada review.

Current status

Working mini-project and public demo. Multilingual accuracy, real-document OCR and downloaded-file acceptance remain under evaluation.

02 / Full-stack AI

AURA FIT AI

Problem

A fitness assistant must preserve user constraints and distinguish educational coaching from medical advice while supporting real accounts, saved history and workout logging.

Architecture

Browser→Worker / session→Coach routing→Training tools→D1 storage

Design decisions

Use a Cloudflare Worker for authenticated application logic and D1 for durable account state. Keep deterministic workout constraints and safety routing explicit; use a separate local Python agent for additional development.

Verification & evidence

Repository quality gates include linting, type checking, web integration tests, authentication and D1 tests, and Python unit tests. Privacy and health boundaries are documented.

Current status

Hosted application with guided workouts, journal and account features. The local agent is a separate development environment; health outputs remain educational.

03 / Network systems

RDTX VisualLab

Problem

UDP does not guarantee delivery, ordering or duplicate suppression. A local protocol lab makes reliability mechanisms observable under controlled loss and reordering.

Architecture

File sender→UDP + impairment→Receiver buffer→ACK / retry→SHA-256 check

Design decisions

Implement Selective Repeat ARQ with per-packet timers and individual ACKs, datagram CRC32 checks and final-file SHA-256 verification. Separate browser telemetry from the actual UDP transport.

Verification & evidence

Multi-version Python CI, real UDP smoke testing, repeatable seeds and matrix experiment exports. The protocol documents fixed timeout, IPv4 and local-demo limitations.

Current status

Runnable educational protocol lab; not a TCP/QUIC replacement or production internet-facing file transfer service.

04 / Edge systems & ML

Edge-AI Digital Twin

Problem

Rotating equipment needs interpretable telemetry and state transitions before real predictive-maintenance claims can be justified.

Architecture

Sensor / simulator→MQTT→Validation + SQLite→Features / inference→Digital twin

Design decisions

Separate telemetry ingestion from condition rules and optional Random Forest inference. Track freshness so missing telemetry becomes UNKNOWN rather than incorrectly reporting HEALTHY. Use explicitly labelled synthetic data for software demos.

Verification & evidence

Documented implementation status, software CI, MQTT and SQLite integration tests, and hardware safety notes. Real sensor calibration and fault-detection validation remain pending.

Current status

Tested software MVP for an academic team project. Physical motor integration and real-world accuracy are not established.

05 / Computer vision · team

ErgoVision

Problem

Posture monitoring needs useful webcam feedback while minimizing the exposure of video data.

Architecture

Webcam→Local pose estimation→Posture metrics→Feedback→React dashboard

Design decisions

Use local computer-vision processing and a dashboard to present posture feedback and session trends. Document privacy boundaries and installation requirements.

Verification & evidence

Backend/frontend checks, a desktop release and repository privacy documentation. This is a collaborative project; individual contributions and attribution are recorded in the repository rather than claimed as sole ownership.

Current status

Collaborative project with a documented desktop release.
